现版缺什么

三列白表，没有表头；且/或夹在条件和指令中间，像是在连后面的按键。
每张卡片只有「条件 / 指令 / 流程控制」；且/或只出现在多个条件之间。
指令是生串，旁边还挂「编辑指令」；流程控制完全藏在子窗口。
点指令模块直接进分支编辑器；流程控制下拉就放在卡片上。
增删靠右键，空列表一大块白，左边还要一排装饰圆点。
添加按钮放在阶梯上；上移/下移/删除悬停才出现，界面更干净。

建议落地时保留的交互

  1. 卡片 = 一条分支。 点指令模块打开现有分支编辑器；主界面只展示条件和关系。
  2. 条件拆成碎片。 Var1 等于 1 显示成变量 / 比较 / 值三块。
  3. 兜底永远钉在最底。 不能上移、不能删除，条件固定为「以上都不是」。
  4. 流程控制在主界面。 无 / 循环-跳过本轮 / 循环-跳出 / 分支-跳出。
  5. 宽度可到 640+。 现 540 把条件和指令挤成一行，信息全糊了。
